# Brisa-PMS-Demo

Brisa is a Cloud-native Property Management System (PMS) that helps small to medium hotels manage Bookings, daily room status, cleaning schedules, and more, all from one platform.

# Project Structure

```text
Brisa-PMS-Demo/
├── BrisaPMS.API/  # Presentation Layer (Controllers, Extensions)
│
├── BrisaPMS.Application/ # Application Layer (Use Cases, Interfaces, Utilities)
│
├── BrisaPMS.Domain/ # Domain Layer (Entities, Value Objects, Domain Exceptions)
│
├── BrisaPMS.Infrastructure/ # Infrastructure Layer (DB Context, Repositories)
│  
└── BrisaPMS.UnitTests/  # Unit test suites for Domain and Application layers.
```

# Pre-Requisites

- .NET 10 or Latest
